# Playwright-Test-Launch-Application-Chatbot-Check

Overview
This project contains a basic Playwright automation test that:
Launches the Zensar website
Interacts with the chatbot icon
Navigates back to the previous page
It is a simple UI smoke test to verify that the application loads correctly and key elements are accessible.

🧪 Test Description
The test performs the following steps:
Opens the Zensar website
Clicks on the chatbot icon using its alternative text
Navigates back to the previous page
